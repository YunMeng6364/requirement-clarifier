# 允许色板

每次开始完整读取本文件与 [palette.json](palette.json)。颜色语义由本次内容决定，模型为分组／模块选择协调的主色，不用颜色推断职责、角色、阶段、状态或成熟度；同一图及关联详图保持已确认映射。按用户后续明确的风格要求，基础设施默认低饱和蓝灰，紫色为辅助且不必出现。该视觉默认不要求增加材料外模块。

`palette.json` 是唯一机器白名单，共47个精确色值，合并规范派 `references/color-spec.md` 的41值与汇报派 `references/style-spec.md` 的26值，交集20值。出处和迁移范围见 [provenance.md](provenance.md)。本文件不另复制职责绑定表，不在执行时提取目录外副本。

源码使用六位小写十六进制色值，必须逐值从 JSON 选择。大小写归一不改变色值；短色值、八位色、颜色名、RGB／HSL函数、CSS变量、近似色禁止。背景、正文、框边、图标、marker、阴影、渐变端点及 defs 中未使用声明都要合规。渲染的渐变插值、抗锯齿和透明混色不是新增声明色；透明度独立写有限数值0..1，不用 rgba 或 transparent 绕过。

`none` 表示不绘制，内部 `url(#id)` 引用须解析至合法资源；图标 symbol 的 `currentColor` 只能从明确合法的 use 实例 color 继承。可见文字／图形不能依赖浏览器默认黑色。连线颜色自由选择白名单色，不强制 `#7f8fab`；同一条线及其 marker 同色，线型本图定义并配图例。

可选既有渐变：背景 `#f4f9ff → #e9f2ff`，蓝 `#3b8bff → #1b57e0`，青绿 `#17b9a5 → #0b8f86`，橙 `#ffb324 → #f08a00`，紫 `#727bff → #5149e8`，蓝灰 `#e8eef8 → #cfd9ea`；纯紫 `#5b6cff` 同样允许。预设不是职责政策；不同搭配仍只用白名单端点并写进一次确认提纲。

白名单只证明色值允许，不证明适合作为主配色。默认以蓝／青绿／橙的饱和渐变和白字标题栏为基准；新增主色组合须保持协调的饱和感、明暗层次、渐变及强色面积，不能随意拿浅底色或突兀色作主标题。无协调组合时复用既有主色，不扩充白名单或自造近似值。具体视觉和验收规则见 [style-spec.md](style-spec.md)。

逐组说明选色理由：区分本图区域、突出主次、保证前景可读或保持详图识别。确认后变更颜色须增量确认；值虽在白名单但偏离冻结映射也属失败。
