# 风格参数与布局

汇报派三模板和17个矢量图标是视觉起点，内容与拓扑每次由输入决定。默认视觉采用用户明确指定的浅蓝背景、饱和主标题栏配白字、白色卡片、细边框和轻阴影。模型按本次内容选择分组颜色；基础设施默认低饱和蓝灰。不强制新增基础设施条，不照抄模板演示模块。

## 配色与文字

全部精确值从 [palette.json](palette.json) 取，规则见 [color-spec.md](color-spec.md)。以下为本技能的默认配色基准：

| 用途 | 精确色值 | 表现 |
|---|---|---|
| 背景 | `#f4f9ff → #e9f2ff` | 很浅的蓝色垂直渐变 |
| 主要蓝色 | `#3b8bff → #1b57e0` | 饱和主标题栏，渐变方向通常从左到右 |
| 主要青绿 | `#17b9a5 → #0b8f86` | 与蓝、橙协调的饱和主标题栏 |
| 主要橙色 | `#ffb324 → #f08a00` | 保持同一视觉体系的主标题栏 |
| 辅助紫色 | `#727bff → #5149e8` | 辅助区分，按内容需要使用 |
| 基础设施蓝灰 | `#e8eef8 → #cfd9ea` | 有意降低饱和度的次级区域，强调可用 `#46618f` |
| 全图标题／正文／辅助说明 | `#12306b`／`#1c2b4a` 或 `#26406e`／`#46618f` | 深蓝标题、深蓝灰正文、较浅的辅助说明 |
| 彩色标题栏文字 | `#ffffff` | 白字，与卡片深色文字分别冻结 |
| 正文卡片 | `#ffffff` 或 `#fafcff` | 白色或极浅色圆角底，不用大面积饱和底承载正文 |
| 细边框 | `#cfe0fb`、`#e1e9f5`，或 `#8db8ff`、`#8fe0d5`、`#ffd27a`、`#b7bfff` | 作为次级描边，不能代替饱和主标题栏 |

主分组／主要机制区默认使用满组宽的饱和渐变标题栏；以 viewBox 宽1920为基准，标题栏高64–80，显式不透明绘制。保持白色正文卡片和浅背景，不要求所有小卡片都铺强色标题，也不要求每图用齐蓝、青绿、橙、紫。组内可用宽4–6、贯穿大部分卡片高度的强色侧条加强识别；需要的侧条与图标在单次提纲列明。不能默认全图淡色标题，仅用短强调条、图标和连线承担强色。

新增主要配色须同时满足色值合规和视觉统一。以蓝、青绿、橙的综合色饱和感、明暗层次和渐变表现为基准，结合相同面积、相同尺寸下的渲染比较；颜色之间不机械要求 HSV／HSL 数字相同。新增组合不能成为突兀的荧光色、异常深暗块或明显更淡的主区，渐变方向、强色面积、标题字重与白字对比也须协调。紫色与基础设施蓝灰属于已明确的辅助／次级层级，不能误当作新增主色的过淡基准。仅在白名单内选择精确端点；没有协调组合时复用现有主色，辅以编号、标签或布局，不能自创或近似色值。每次在提纲说明新增主色的协调依据，目视验收再次核对。

彩色标题栏配白字。白字使用清楚的粗体和足够字号，尽量落在渐变较深处；亮端仍不清楚时，使用提纲已批准的白名单深色衬底／遮罩和独立透明度，保留主渐变并实际渲染查看。新增遮罩／装饰在提纲登记，不能任意自造更深色，也不能以可读性为由将全部主标题退回浅色底。关键条件放白卡正文区，用深色文字，不用浅色或微小字号弱化。

同对象在本图和关联详图使用同名、同编号、同配色，不只靠颜色表达状态或关系：辅以标签、条件或图例。连线线型每张图有明确含义，不按旧业务固定为同步／异步。连线和箭头同色、端点停对象边界。

## 字体与展示尺度

字体族：`"Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", "Source Han Sans SC", Arial, sans-serif`，用本机回退，不下载或嵌入远程字体；文字保持 text/tspan，不转路径。源模板是结构示范，字体在每次目标环境复核。

以viewBox宽1920为基准：

| 文字层级 | 默认字号 | 用法 |
|---|---|---|
| 全图标题 | 44–48 | 粗体，长标题允许换行 |
| 分组／阶段标题 | 28–30 | 清楚区分区域 |
| 模块／节点标题 | 26 | 常规粗体或半粗体 |
| 正文 | 24，紧凑时22 | 行距1.35–1.5，不持续缩小来塞模板 |
| 图例／说明 | 20 | 关键条件使用正文级别 |
| 非关键边注 | 18 | 不承载复杂机制或验收关键文字 |

展示字号约等于源码字号×展示宽÷viewBox宽。1920画布的24在1600宽约20px、在1280宽约16px。SVG能放大不证明单页缩略可读。纵向图按可阅读宽度滚读并看局部，不缩进16:9后宣布投屏验收。CSS字体规则不要覆盖显式标题字号；默认字号用根presentation属性，各文字可明确覆盖。

## 几何、空白与换行

| 参数 | 默认 | 调整 |
|---|---|---|
| 外边距 | 48–60 | 标题／箭头／阴影需要时扩大 |
| 分组间距 | 24–32 | 提前预留关系通道 |
| 卡片内边距 | 24–32 | 长标题和多正文扩展区域 |
| 圆角 | 卡片16–20，主组24–32 | 不同层级区分 |
| 描边 | 1.5–2 | 强调可以稍粗，不能压过文字 |
| 阴影 | dx0、dy4、stdDeviation5、`#2864dc`、opacity0.12 | 可减弱／去除；新增须获批 |
| 阴影范围 | x/y=-20%，width140%，height145% | 必须实际查看无裁切 |

同层卡片尺寸／编号／对齐统一；内容差距较大可不同宽或分组。长文字按语义切分原字符串，保留有意义空格和字符，不用省略号截断。SVG文字不会自动换行。不能通过clipPath藏溢出；标题栏局部圆角裁切只作用几何。

先预留连线通道再布卡片。顺序、调用、数据流、分支、并行、反馈、包含分别按真实关系画；架构层上下相邻不自动加执行箭头。分支写条件，并行有拆分／汇合，反馈有目标和独立返回通道；跨线与汇合点明确区分。

## 图标与模板

`assets/icons.svg` 提供17个24×24 symbol，轮廓1.8、圆端点和圆连接，适量填充。通常展示28–36，入口／阶段40–44，同用途保持尺度和笔触。只复制所需symbol进本图defs并用内部href，不能留下 `icons.svg#id` 外部依赖，不依赖Emoji字体，也不代替关键名称。

`overview-detail.svg` 表达阶段总览和局部机制；`layers.svg` 表达纵向分层或网格；`flow.svg` 表达横向流程、分支、反馈。八拓扑用这些组件显式重排，非自动布局引擎；更多模块／条件时扩区域或使用批准的拆图。模板中的业务和数量不是默认事实。

色值已迁移到47值并集；预览必须关联当前SVG并目视，字体lookup只是环境提示。执行和检查见 [verification.md](verification.md)。
